## ADDED Requirements

### Requirement: CostGuard optimization outputs are runway-consumable
The system SHALL expose CostGuard recurring-savings opportunities and confidence metadata so RunwayGuard can estimate runway improvement from cost actions.

#### Scenario: CostGuard opportunities displayed in runway actions
- **WHEN** RunwayGuard composes recommendations
- **THEN** CostGuard opportunity values are represented as potential runway impact estimates with confidence context
