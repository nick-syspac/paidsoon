## ADDED Requirements

### Requirement: SpendLeak savings lifecycle informs runway estimates
The system SHALL expose identified, planned, and realized savings states in a form consumable by RunwayGuard so potential runway impact is distinguished from realized improvement.

#### Scenario: Savings lifecycle consumed by runway recommendations
- **WHEN** RunwayGuard requests SpendLeak savings context
- **THEN** SpendLeak provides lifecycle-qualified savings amounts that support estimate labeling
